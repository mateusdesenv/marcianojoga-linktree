# MARCIANOJOGA — Árvore de links

Página responsiva de links do streamer MARCIANOJOGA, criada em HTML, CSS e JavaScript puro.

## Recursos

- Visual gamer minimalista em preto e verde neon
- Avatar ilustrado do perfil
- Links para redes sociais e contato comercial
- Compartilhamento nativo com alternativa de cópia
- Navegação por teclado e suporte a movimento reduzido

## Executar localmente

```bash
python3 -m http.server 4175 --bind 127.0.0.1
```

Abra `http://127.0.0.1:4175/`.

## Observação

Confirme os endereços de YouTube, Twitch, Instagram e contato comercial antes de divulgar a página.
